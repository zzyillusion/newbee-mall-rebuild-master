# 图书商城管理系统
> 本项目基于新蜂商城开源项目二次改造，将通用商品模块改造为图书模块，后端采用SpringBoot + MyBatis + MySQL开发，实现图书信息管理、图书分页查询等基础功能。

## 技术栈
- 后端：Java 8，SpringBoot 2.7.5，MyBatis
- 数据库：MySQL 8.0
- 构建工具：Maven
- IDE：IntelliJ IDEA
- 数据库工具：DataGrip

## 项目改造说明（个人开发部分，重点！）
原项目为通用电商商城，本人对商品模块进行定制改造，改造内容：
1. 修改数据库商品表，新增图书专属字段：ISBN、作者、出版社；
2. 同步修改实体类`NewBeeMallGoods`，增加对应属性、get/set方法；
3. 修改MyBatis Mapper XML映射文件，新增字段resultMap映射、insert/update语句；
4. 新增根据ISBN查询图书的接口；
5. 清空原有商品测试数据，导入图书样例数据，支持图书列表分页查询；
6. 解决改造过程中遇到的JDK版本兼容、MyBatis字段映射不一致等问题，项目可完整启动。

原有复用模块：用户登录、后台管理、分页工具、全局异常处理等（开源项目原有代码）

## 环境准备
1. JDK 8
2. Maven 3.6+
3. MySQL8.0
4. 配置数据库，创建数据库并执行项目SQL脚本，导入图书数据

## 启动步骤
1. 将项目克隆/下载到本地，IDEA打开项目，等待Maven加载依赖
2. 修改application配置文件，填写自己的MySQL地址、用户名、密码
3. 在DataGrip中执行sql脚本，初始化表结构和图书测试数据
4. 运行项目启动类，启动成功后访问：`http://localhost:8080`

## 项目功能
✅ 图书信息CRUD
✅ 根据ISBN查询图书
✅ 图书列表分页展示
✅ 后台图书管理
✅ 用户前台浏览图书

## 遇到的问题&解决方案
1. MyBatis查询不到新增字段：数据库新增字段后，忘记同步修改xml的resultMap映射，补齐映射后解决
2. JDK版本不匹配：原项目要求JDK8，本地JDK版本过高，修改pom编译版本，调整IDEA项目SDK
3. SQL导入报错：执行脚本前没有选中对应数据库，切换数据库后执行成功
